## Installation
### Option simple
1. Ouvre ton repo GitHub.
2. `Add file` → `Upload files`
3. Dépose les **3 fichiers** ci-dessus pour les remplacer.
4. Commit : `V4.2 - territoires maintenant`
5. Attends le workflow vert.
6. Recharge la page avec un hard refresh.

### Option complète
Tu peux aussi reprendre tout le contenu de ce dossier si tu préfères.
