# Radar Immobilier V4 — Premium & Profils

Cette mise à jour regroupe les corrections visuelles et fonctionnelles demandées.

## Nouveautés

### Design plus premium
- Palette ivoire / vert nuit / cuivre / champagne.
- Accents officiels moins agressifs.
- Typographie et contrastes renforcés.

### Textes plus percutants
- Baromètre : message plus court et plus décisionnel.
- Pulse : prix / crédit / location reformulés.
- Hero adapté au profil.

### Profils réellement fonctionnels
Les boutons changent maintenant :
- le classement des informations ;
- le score de pertinence ;
- le titre du fil ;
- le texte du hero ;
- le bloc « Pourquoi c’est important » ;
- la lecture du baromètre.

Particulier privilégie : achat, crédit, DPE, travaux, location.
Investisseur privilégie : rendement, fiscalité, loyers, financement.
Professionnel privilégie : réglementation, volumes, construction, agences, syndic, proptech.

### Correctifs visuels
- Plus de chevauchement Radar des lois / Sources vérifiées.
- Sidebar en pile sur tablette et mobile.
- Chiffres du baromètre non cassables : +0,2 %, 952 000, -8,0 %.
- Alignement stable des KPI.
- Responsive renforcé.
