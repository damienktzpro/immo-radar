# Checklist avant d'envoyer le lien

1. GitHub Actions → `Update Immo Radar` doit être vert.
2. Vérifier `Santé du radar` : idéalement aucune source en erreur sans repli.
3. Ouvrir 3 articles au hasard et confirmer que les boutons pointent vers l'article exact.
4. Tester les trois profils : Particulier, Investisseur, Professionnel.
5. Tester au moins deux territoires connus.
6. Vérifier que prix, loyers, transactions et DPE affichent bien leur période / méthodologie.
7. Tester la loupe avec : `DPE`, `LMNP`, `crédit immobilier`, `encadrement loyers`.
8. Tester mobile rapidement.
9. Utiliser le bouton `Feedback` pour vérifier que le retour peut être copié.
10. Ne pas présenter le 48/100 comme un chiffre officiel : c'est l'indice synthétique du Radar.
